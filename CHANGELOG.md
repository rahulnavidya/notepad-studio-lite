# Changelog

Notable project changes are recorded here.

## Pass 3 — 2026-11-17

- Final reviewed single-file application artifact.
- Native file workflow: Open, Save, Save As, and Export Copy, using the File System Access API where available with import/download fallbacks.
- Session-only file associations and linked-file status indicators.
- Multi-document editing, per-document tabs, rename and duplicate actions.
- Find and replace within a document and search across open documents.
- 41 design languages and 40 built-in colour themes.
- Custom theme creation, appearance presets, favourites, and recent appearance history.
- Editor preferences including line numbers, word wrap, spellcheck, font, font size, line height, and tab width.
- Workspace JSON backup and validated restore.
- Responsive layout and command palette.
- Final QA recorded as 571/571 browser checks passing, plus passing T0 static checks. See [Quality Assurance](docs/QUALITY-ASSURANCE.md).
