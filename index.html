Workspace

Autosave keeps everything in this browser. “Open” loads text files from your computer; “Save” writes back to the linked file; “Export Copy” downloads a standalone .txt.

“Back up workspace” packs every document together with settings, custom themes, presets and history into one .json file that “Restore backup” can rebuild here. Restoring is validated first and never happens partially. File links are session-only: they are not stored and do not survive a reload.

About

A zero-dependency plain-text editor. Everything you type stays literal — no formatting, no rendering, no Markdown. Documents and settings live in this browser's localStorage; “Back up workspace” exports everything as JSON.

Notepad Studio Lite — Pass 3. 41 design languages, 40 built-in colour themes, custom theme creator, appearance presets, favourites and history, full editor preferences, command palette, cross-document search, and a native file workflow: Open, Save, Save As and Export Copy, using the File System Access API where available with graceful fallbacks.
