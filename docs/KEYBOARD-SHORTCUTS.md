# Keyboard Shortcuts

The following shortcuts are listed in the Pass 3 application's own Shortcuts pane.

| Shortcut | Action |
|---|---|
| `Ctrl+Alt+N` | New document |
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save to the linked file |
| `Ctrl+Shift+S` | Save As |
| `Ctrl+F` | Find and replace |
| `F3` / `Shift+F3` | Find next / previous |
| `Ctrl+Shift+F` | Search all documents |
| `Ctrl+G` | Go to line |
| `Ctrl+Alt+D` | Duplicate document |
| `F2` | Rename document |
| `Alt+W` | Close document |
| `Ctrl+Alt+1–9` | Switch to tab |
| `Alt+Shift+←/→` | Move current tab |
| `Tab` / `Shift+Tab` | Indent / outdent line while in the editor |
| `Ctrl+Shift+P` | Open command palette |
| `Esc` | Close search, dialog, or drawer |

## Notes

- These are the shortcuts documented inside the application.
- Keyboard handling can vary with browser, operating system, keyboard layout, and system-level shortcuts.
- The app's documented combinations use `Ctrl`; the table does not claim that every combination maps automatically to `Command` on macOS.
- While the editor has focus, `Tab` and `Shift+Tab` indent and outdent text rather than moving focus to another control.
