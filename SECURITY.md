# Security Policy

## Scope

This policy covers the Notepad Studio Lite repository and its browser-based application.

## Reporting a vulnerability

Please do not publish details of an exploitable security issue in a public issue before the maintainer has had a chance to assess it.

Use GitHub's private vulnerability reporting feature for this repository when it is available. If private reporting is not enabled, contact the repository owner through their GitHub profile and provide a concise report.

Include:

- A description of the issue and its impact.
- Reproduction steps or a proof of concept that does not expose real user data.
- Affected browser and operating-system versions.
- Any suggested mitigation.

## Security expectations

Notepad Studio Lite stores workspace data in browser local storage and uses browser-managed file APIs. It does not claim to encrypt local data. Users should protect their browser profile and workspace backup files accordingly.
